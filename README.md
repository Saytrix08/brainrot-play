# Brainrot Karten – im Browser spielen

Kartensammelspiel mit Brainrot-Figuren: Packs öffnen, seltene Karten finden, Album vollmachen.
Hier liegt nur das fertige Spiel für den Browser, der Quellcode ist privat.

**Spielen:** https://saytrix08.github.io/brainrot-play/

Auf dem iPad: Link in Safari öffnen → Teilen → **Zum Home-Bildschirm**, danach immer über das Symbol starten.
